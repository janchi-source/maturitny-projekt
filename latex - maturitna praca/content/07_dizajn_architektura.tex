\chapter{Dizajn a architektúra}

        V~tejto kapitole opisujeme celkovú architektúru systému, štruktúru zdrojového kódu
a~návrh používateľského rozhrania. Správny architektonický návrh je základom udržiavateľnej
a~rozšíriteľnej aplikácie.

\section{Architektúra systému}

        Aplikáciu sme navrhli ako klasickú klient-server webovú aplikáciu s~trojvrstvovou
architektúrou:

\begin{itemize}
  \item \textbf{Prezentačná vrstva} -- HTML/CSS/JavaScript šablóny (Jinja2~\cite{jinja2_docs}), ktoré
        renderuje Flask~\cite{flask_docs} a~zasiela klientovi cez HTTPS.
  \item \textbf{Aplikačná vrstva} -- Flask blueprinty obsahujúce business logiku:
        spracovanie požiadaviek, autorizáciu, komunikáciu s~AI~modelom a~extrakciu
        textu z~dokumentov.
  \item \textbf{Dátová vrstva} -- SQLAlchemy~\cite{sqlalchemy_docs} ORM modely komunikujúce s~SQLite~\cite{sqlite_org}
        databázou. Súbory dokumentov sú uložené na filesystéme servera.
\end{itemize}

        Kód sme rozdelili do samostatných Flask blueprintov podľa funkčných celkov:
\texttt{auth}, \texttt{dashboard}, \texttt{projects}, \texttt{tasks}, \texttt{documents},
\texttt{ai\_chat}, \texttt{team} a~\texttt{settings}. Každý blueprint obsahuje vlastné
routes, šablóny a~pomocné funkcie, čo umožňuje nezávislý vývoj a~testovanie jednotlivých
modulov.

\section{Štruktúra projektu}

        Zdrojový kód aplikácie sme organizovali nasledovne:

\begin{itemize}
  \item \texttt{app/} -- hlavný adresár aplikácie
  \begin{itemize}
    \item \texttt{blueprints/} -- jednotlivé moduly (auth, projects, tasks, \ldots)
    \item \texttt{models/} -- SQLAlchemy modely databázových entít
    \item \texttt{services/} -- servisná vrstva (extrakcia textu, AI~komunikácia)
    \item \texttt{templates/} -- Jinja2 HTML šablóny
    \item \texttt{static/} -- CSS, JavaScript, obrázky
  \end{itemize}
  \item \texttt{config.py} -- konfigurácia aplikácie (databáza, AI, bezpečnosť)
  \item \texttt{run.py} -- vstupný bod pre spustenie servera
  \item \texttt{requirements.txt} -- zoznam Python závislostí
  \item \texttt{uploads/} -- adresár pre nahrané dokumenty
  \item \texttt{instance/promat.db} -- SQLite databázový súbor
\end{itemize}

\section{Používateľské rozhranie}

        Používateľské rozhranie sme navrhli s~dôrazom na jednoduchosť a~prehľadnosť.
Každá stránka obsahuje fixný bočný panel (sidebar) s~navigáciou a~hlavný obsahový
priestor. Aplikácia podporuje svetlý aj tmavý režim, pričom používateľova voľba je
uložená lokálne.

        Rozhranie obsahuje nasledujúce kľúčové obrazovky:

\begin{itemize}
  \item \textbf{Dashboard} -- prehľad projektov, úloh a~aktivity (obr.~\ref{fig:ui_dashboard})
  \item \textbf{Zoznam projektov} -- prehľad všetkých projektov s~filtráciou
  \item \textbf{Detail projektu} -- úlohy, dokumenty a~členovia projektu
  \item \textbf{Kanban tabuľa} -- drag-and-drop zobrazenie úloh podľa stavu (obr.~\ref{fig:ui_kanban})
  \item \textbf{Dokumenty} -- nahrávanie, prezeranie a~AI~chat nad dokumentmi
  \item \textbf{AI~chat} -- konverzačné rozhranie pre prácu s~dokumentmi
\end{itemize}
