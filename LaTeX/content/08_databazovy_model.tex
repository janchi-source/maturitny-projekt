\chapter{Databázový model}

        Databázový model je základom celej aplikácie. Definuje štruktúru uložených
dát, vzťahy medzi entitami a~obmedzenia integrity. Všetky modely sú implementované
pomocou SQLAlchemy ORM a~mapované na tabuľky SQLite databázy.

\section{Entitno-relačný diagram}

        Aplikácia pracuje s~ôsmimi hlavnými entitami, ktoré sú vzájomne prepojené
reláciami. Diagram zachytáva vzťahy medzi používateľmi, projektmi, úlohami,
dokumentmi a~podpornými entitami.

        Hlavné vzťahy medzi entitami:

\begin{itemize}
  \item Jeden \textbf{User} môže byť členom viacerých \textbf{Project}ov (M:N cez tabuľku členstva).
  \item Jeden \textbf{Project} obsahuje viaceré \textbf{Task}y (1:N).
  \item Jeden \textbf{Task} môže mať priradených viacerých používateľov (M:N).
  \item Jeden \textbf{Project} môže mať viacero \textbf{Document}ov (1:N).
  \item Každý \textbf{Document} môže byť asociovaný s~konkrétnou \textbf{Task}ou.
  \item \textbf{Comment}y patria k~\textbf{Task}u alebo \textbf{Document}u (polymorfná relácia).
  \item \textbf{Notification}e sú adresované konkrétnemu \textbf{User}ovi.
\end{itemize}
